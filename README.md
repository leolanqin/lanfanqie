# 巡检仪表识别系统

基于 **机器人** + **ROS 2** + **OpenClaw** + **Qwen3-VL-Plus** 的全自动工业仪表巡检与识别系统。

## 系统架构

```
┌─────────────────────────────────────────────────┐
│                OpenClaw（控制中枢）             |
│  run-inspection.sh → 编排巡检流程               |
│  start/stop_inspection.sh → 启动/停止           │
│  check_progress.sh → 进度推送                   │
│  img-understand.sh → 调用视觉模型               │
└────────────┬────────────┬─────────────┬─────────┘
             │ HTTP       │ HTTP        │ ROS 2
             ▼            ▼             ▼
┌───────────────────┐ ┌────────────┐ ┌──────────────┐
│  Inspection       │ │  Floors    │ │  Nav Server  │
│  Server (Flask)   │ │  Server    │ │  (ROS Node)  │
│  :8001            │ │  :8000     │ │              │
│                   │ │            │ │ /nav/goal    │
│  /upload          │ │            │ │ /floor_change│
│  /api/results     │ │            │ │              │
│  /api/progress    │ │            │ │              │
│  dashboard.html   │ │            │ │              │
└───────────────────┘ └────────────┘ └──────────────┘
```


## 核心流程

### 一键巡检

```
开始巡检 → 机器人逐个导航到点位 → 拍照 → 上传服务器
→ AI 识别仪表 → 记录结果 → 导航到电梯口 → 换层
→ 继续巡检 → 全部完成
```

### 触发方式

在 OpenClaw 聊天中（Web 控制台 / 飞书）：

|     指令     |         功能           |
|--------------|------------------------|
| `开始巡检`   | 正向巡检（按 plan 顺序）|
| `倒回去`     | 反向巡检（逆序）        |
| `停下巡检`   | 中断当前巡检            |

### 进度显示

- **Web 控制台**：实时弹窗推送进度
- **飞书**：完成后发送摘要
- **仪表盘 (dashboard.html)**：实时进度条 + 历史记录
